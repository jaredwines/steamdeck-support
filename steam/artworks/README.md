# Steam artwork backups

This folder stores per-game or per-launcher artwork backups. Each collection
should contain the four images described in the
[setup guide](../add-non-steam-game-and-artwork-guide.md): a wide cover,
portrait cover, hero background, and transparent title logo.

Use a dedicated subfolder for each title. Keep the hero title-free and the logo
transparent. Each collection README must record the source or creation method,
redistribution status, format-validation date, SteamOS build used for on-device
verification, and the four Gaming Mode views checked. Use `not recorded` or
`not tested on-device` instead of making an unsupported claim.

Do not store secrets or unrelated files with the artwork. Do not redistribute
an asset whose rights or source have not been established.
