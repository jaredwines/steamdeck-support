# Steam guidance and assets

This folder contains the detailed guide for non-Steam games, launchers, and
their artwork. Use the
[Non-Steam Game & Artwork Setup Guide](add-non-steam-game-and-artwork-guide.md)
for the repeatable setup procedure. Artwork backups are in
[artworks/](artworks/README.md).

Add only verified guidance or the intended artwork backup. Do not commit
account credentials, private keys, tokens, or sensitive diagnostics.
