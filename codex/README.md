# Codex instructions

This folder contains the instructions that guide Codex when it works in this
repository. Read [AGENTS.md](AGENTS.md) before making support-related changes.

Keep this guidance aligned with the repository's root
[AGENTS.md](../AGENTS.md). Do not add credentials, private keys, passwords, or
sensitive diagnostic output.

Before publishing an intended documentation change, run `git status`, stage
only the intended files, review `git diff --cached`, then commit and push from
the repository root. See the [repository README](../README.md) for the full
workflow.
