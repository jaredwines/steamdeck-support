# Private support-session record template

Copy this template outside Steam Deck Support before filling it in. Do not
commit a completed record. Remove passwords, private keys, tokens, host-key
material, account data, local addresses, device identifiers, and unrelated log
content before sharing any excerpt.

```text
Date and operator:
Owner-approved objective:
Device identity verified locally:
SteamOS version/build:
Kernel:
Connection type:
Applicable runbook and section:

Starting symptom and scope:
Prerequisites checked:
Approval boundary:
Expected result:
Recovery plan and backup location:

Commands and UI actions performed:
Files or settings changed:
Observed result:
Functional check:
Gaming Mode check, if significant:
Recovery available or tested:

Temporary sudo cleared:
Remote access disposition:
Unresolved risks and deferred work:
Reusable sanitized finding for SS:
Owner handoff and acceptance:
```

When the session is complete, update an SS runbook only if the finding is
verified, reusable, sanitized, and includes its compatibility evidence. Keep or
destroy the private record according to the owner's retention preference.
